نام پروژه: AI-RockPaperScissors
بازی سنگ، کاغذ، قیچی با تشخیص دست از طریق وب‌کم (کاملاً آفلاین)

منبع و لایسنس:
- MediaPipe Hand Landmarker از Google AI Edge (لایسنس Apache 2.0)
- مخزن اصلی مدل‌ها: https://github.com/google-ai-edge/mediapipe
- فونت وزیرمتن (Vazirmatn) - SIL Open Font License

روش اجرا:
1. کل پوشه AI-RockPaperScissors را روی فلش USB کپی کنید.
2. روی لپ‌تاپ (ویندوز ۱۰ یا ۱۱) پوشه را باز کنید.
3. روی فایل start.bat دوبار کلیک کنید.
4. مرورگر به صورت خودکار باز می‌شود و بازی شروع می‌شود.
5. اجازه دسترسی به دوربین را بدهید.

نکته‌ها:
- اگر آنتی‌ویروس هشدار داد، گزینه Allow / اجازه را انتخاب کنید.
- وب‌کم لپ‌تاپ باید وصل و فعال باشد.
- اینترنت لازم نیست. همه چیز داخل پوشه است.
- برای خروج، پنجره سیاه (cmd) را ببندید.

اگر دوربین کار نکرد:
- اجازه دسترسی دوربین را در تنظیمات مرورگر بررسی کنید.
- مطمئن شوید برنامه دیگری از دوربین استفاده نمی‌کند.
- صفحه را رفرش کنید یا start.bat را دوباره اجرا کنید.
