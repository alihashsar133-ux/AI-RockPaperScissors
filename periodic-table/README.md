# جدول تناوبی ۳۸ عنصر نخست (PDF)

یک پوسترِ تک‌صفحه‌ای و چشم‌نواز از ۳۸ عنصر نخست جدول تناوبی
(از هیدروژن `Z=1` تا استرانسیم `Z=38`) با چیدمانِ استاندارد IUPAC.

**خروجی:** [`output/periodic-table-first-38-elements.pdf`](output/periodic-table-first-38-elements.pdf)
— یک صفحه، A3 افقی (۱۱۹۱×۸۴۲ pt)، آمادهٔ چاپ.

## اطلاعات هر خانه

| آیتم | توضیح |
|---|---|
| **عدد اتمی (Z)** | شمار پروتون‌های هسته — گوشهٔ بالا-چپ خانه |
| **عدد جرمی (A)** | پروتون + نوترونِ فراوان‌ترین ایزوتوپ پایدار طبیعی — گوشهٔ بالا-راست |
| **جرم اتمی میانگین** | میانگین وزن‌دار جرم ایزوتوپ‌های طبیعی بر حسب فراوانی، بر حسب واحد جرم اتمی (u) — در کپسولِ پایین خانه |
| **نماد و نام** | نمادِ لاتین در مرکز، نامِ فارسی در زیر آن |

رنگِ هر خانه نشان‌دهندهٔ **دستهٔ عنصر** است (راهنمای رنگ‌ها در پایینِ پوستر).

## درستیِ گروه‌ها

چیدمان دقیقاً از استاندارد IUPAC پیروی می‌کند و گروه‌ها دست‌نخورده‌اند:

* **هلیم در گروه ۱۸** (با وجودِ ۲ الکترونِ ظرفیت) — نه در گروه ۲.
* **هیدروژن در گروه ۱** (قراردادیِ IUPAC).
* بلوکِ d دورهٔ ۴ (اسکاندیم `Z=21` تا روی `Z=30`) در گروه‌های **۳ تا ۱۲**،
  پیش از گروه‌های ۱۳ تا ۱۸ همان دوره.
* بازهٔ خالیِ دورهٔ ۵ با کادری خط‌چین مشخص شده است تا جای عنصر ۳۹ (ایتریم) و
  عنصرهای پس از آن خالی نماند و ساختارِ جدول درک شود.

`elements_data.py` این قواعد را به‌صورت خودکار می‌آزماید:

```bash
python elements_data.py
# OK: 38 عنصر - گروه/دوره یکتا و سازگار با چیدمان IUPAC
```

## اجرا

```bash
pip install -r requirements.txt
python build_periodic_table.py
```

فونت فارسی (**وزیرمتن**) در `assets/fonts/` قرار دارد و همراهِ مخزن است،
بنابراین خروجی روی هر سیستمی یکسان رندر می‌شود.

## نکته‌های پیاده‌سازی

* **حروف‌چینی فارسی:** `arabic_reshaper` فرم‌های چسبان را می‌سازد و
  `python-bidi` ترتیب بصری را تعیین می‌کند؛ اعداد و نمادهای لاتین بدون
  shaping رسم می‌شوند تا جهتِ آن‌ها به‌هم نخورد.
* **گرادیان در reportlab:** دو دامنهٔ مهم که در این پروژه لحاظ شده‌اند:
  1. دستورِ شیدینگ کلِ ناحیهٔ جاری را پر می‌کند، مگر اینکه پیش از آن
     مسیر محدود شود (`clipPath`) — تابعِ `radial_spot` این کار را می‌کند.
  2. توقف‌هایِ رنگِ **آلفادار** باعث می‌شوند گرادیان یکدست و «تخت» رندر شود؛
     بنابراین توقف‌ها باید کدر باشند و شفافیت با `setFillAlpha` اعمال شود.
* `rrect` و توابعِ متن، آلفایِ درونِ شیءِ رنگ را در آلفایِ صریح ضرب می‌کنند،
  چون فراخوانیِ `setFillAlpha` آلفایِ خودِ رنگ را بازنویسی می‌کند.

## منبع داده‌ها

* جرم‌های اتمی: **IUPAC CIAAW — Standard Atomic Weights، ویرایش ۲۰۲۱**
  (مقادیر خلاصه‌شده/متعارف).
* گروه و دوره: چیدمان استاندارد IUPAC (گروه‌های ۱ تا ۱۸).
